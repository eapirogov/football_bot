# Football Bot — Telegram-бот футбольного расписания

Курсовая работа: Telegram-бот, который уведомляет пользователя о матчах его
любимых команд и лиг, показывает турнирные таблицы и по запросу присылает
развёрнутую статистику матча.

## Основные возможности

**Подписки**
- на отдельные **команды** (без ограничения по количеству)
- на целые **лиги** — уведомления по всем матчам турнира
- просмотр и отписка через «Мои подписки»

**Уведомления** (три вида на каждый матч)
- `pre` — напоминание перед началом, интервал выбирает пользователь:
  **10 / 15 / 20 / 30 / 60 минут**
- `kickoff` — сигнал в момент стартового свистка
- `post` — итоговый счёт с inline-кнопкой «📊 Статистика»

**Матчи и таблицы**
- ближайшие матчи по подпискам (`/upcoming`)
- последние завершённые матчи с результатами (`/results`)
- турнирная таблица любой поддерживаемой лиги (`/table`)
- статистика матча: голы, ассисты, жёлтые/красные карточки, владение мячом, удары

**Настройки** (`/settings`)
- уведомления вкл/выкл
- интервал напоминания перед матчем
- **часовой пояс из 13 вариантов** — 11 российских (Калининград … Камчатка)
  плюс Лондон и Берлин/Париж. Время матчей показывается в поясе пользователя.

## Стек

| Слой | Технология |
|---|---|
| Telegram | aiogram 3.x |
| База данных | PostgreSQL + SQLAlchemy 2.0 (async) + asyncpg |
| Миграции | Alembic (6 ревизий) |
| Планировщик | APScheduler с PostgreSQL JobStore |
| Источник данных | **football-data.org API v4** |
| HTTP | httpx (с обработкой 429 и повторами) |
| Конфигурация | python-dotenv + dataclass |
| Хостинг | Railway (`railway.toml`) |

## Схема БД (11 таблиц)

| Таблица | Назначение |
|---|---|
| `users` | Telegram-пользователи (id, username) |
| `user_settings` | уведомления вкл/выкл, интервал `pre_match_minutes`, часовой пояс |
| `leagues` | справочник лиг (заполняется сидом) |
| `teams` | справочник команд |
| `venues` | стадионы |
| `favorite_teams` | подписки пользователей на команды |
| `favorite_leagues` | подписки пользователей на лиги |
| `fixtures` | кэш матчей: статус, счёт, время начала в UTC |
| `fixture_stats_cache` | кэш событий и статистики матча (JSONB) |
| `standings_cache` | кэш турнирных таблиц по лиге и сезону (JSONB) |
| `notifications` | запланированные/отправленные уведомления, UNIQUE по `user + fixture + kind` |

```
users ──┬── user_settings
        ├── favorite_teams ──── teams ──── league_id ──┐
        └── favorite_leagues ── leagues ──────────────┤
                                                      │
        fixtures (league_id, home_team_id, away_team_id, kickoff_utc, status, scores)
           ├── fixture_stats_cache
           └── notifications (kind: pre | kickoff | post)
```

## Логика уведомлений

1. При старте и каждые **6 часов** (`SYNC_INTERVAL_HOURS`) джоб `sync_fixtures`
   тянет матчи на ближайшие **7 дней** по поддерживаемым лигам и складывает их
   в `fixtures`.
2. Для каждого матча собираются подписчики — и по командам, и по лигам.
3. В `notifications` пишется запись с защитой от дублей (UNIQUE по
   `user_id + fixture_id + kind`), а в APScheduler регистрируется one-shot job:
   - `pre` — за выбранные пользователем минуты до начала
   - `kickoff` — в момент начала матча
   - `post` — через 110 минут после начала (`POST_MATCH_MINUTES`)
4. APScheduler хранит джобы в PostgreSQL (`apscheduler_jobs`), поэтому
   уведомления переживают рестарт бота.
5. `notifier.send_post()` дополнительно сверяет реальный статус матча — на
   случай дополнительного времени.
6. При отписке от команды или лиги запланированные уведомления отменяются.
7. По кнопке «📊 Статистика» `handlers/stats.py` берёт события и статистику из
   API (с кэшем в `fixture_stats_cache`) и форматирует ответ.

## Поддерживаемые турниры

12 турниров, доступных на бесплатном тарифе football-data.org:

| Код | Турнир | Код | Турнир |
|---|---|---|---|
| `PL` | Премьер-лига (Англия) | `CL` | Лига Чемпионов УЕФА |
| `PD` | Ла Лига | `WC` | Чемпионат мира |
| `SA` | Серия А | `EC` | Чемпионат Европы |
| `BL1` | Бундеслига | `ELC` | Championship (Англия) |
| `FL1` | Лига 1 | `DED` | Эредивизи |
| `PPL` | Примейра (Португалия) | `BSA` | Бразилейрао |

Список настраивается в `bot/config.py` (`LEAGUE_CODES` и `LEAGUE_ID_MAP`).
